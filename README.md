# Movie Collection Manager (Android - Java)

An Android application developed using Android Studio and Java, designed to help users organize and manage their personal entertainment libraries using local database storage.

## 🚀 Features
- **Local DB Storage:** Uses SQLite to create, read, update, and delete movie records.
- **Dynamic List View:** Implements `RecyclerView` and `CardView` to seamlessly display lists with shadows and rounded corners.
- **Favorites System:** Users can add/remove movies to/from a dedicated favorites list.
- **Advanced Search:** Real-time search filtering to find movies by title instantly.
- **UX Best Practices:** Modal `DialogFragment` for delete confirmations and handled Empty States for the favorites screen.

## 🛠️ Tech Stack & Components
- **Language:** Java
- **Database:** SQLite
- **UI Components:** RecyclerView, CardView, DialogFragment, ScrollView, SearchView
